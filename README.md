# Maltoso — tabela de preços

Preços de referência de insumos cervejeiros (BH Brew → Piquiri) usados pelo app [Maltoso](https://maltosoapp.com.br).

- `precos.json`: atualizado todo dia por uma tarefa automática.
- Formato: `{updated, fonte, items: [[chave, preço, loja, observação, dataConferida], ...]}`.
  - `F|Nome|Fabricante`: malte, R$/kg
  - `H|Nome`: lúpulo, R$/g
  - `Y|Nome`: levedura, R$/unidade
